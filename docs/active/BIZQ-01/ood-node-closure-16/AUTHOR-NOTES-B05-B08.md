## Cross-unit overlap checks

- B05 questions classify the scenario’s business vocabulary and scoped term meanings. They do not ask whether a concept is an entity/value object or where a multi-record operation belongs (B03).
- B06 asks which boundary owns a behavior or technical responsibility under stated ownership/caller facts. Cross-object calculation is placed in a domain service only where the prompt says no single object owns the reusable policy; this is not a blanket cross-object rule. It differs from B03’s concept classification.
