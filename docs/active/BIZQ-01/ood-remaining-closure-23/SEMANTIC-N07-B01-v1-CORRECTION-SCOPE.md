# N07-B01 v1 review clarification: correction scope

This note supplements, and does not rewrite, the frozen `SEMANTIC-N07-B01-v1-QA.md` / JSON. The earlier instruction “do not pad or remove options” was too categorical. The existing BIZQ-01 §4.3 says to prefer fewer meaningful alternatives over artificial filler, provided a reduction satisfies the active schema, scoring, and mode contract. There is no independent requirement to keep five choices.

The blocking finding is unchanged: all 18 frozen B01 items have a uniquely longest keyed option, which creates the systematic form cue §4.3 expressly says to remove. A coherent correction may either retain five options while rewriting distractors as credible, comparably concrete competing policies, or remove an actual filler distractor if the existing choice-mode contract permits the reduced set. Do not pad distractors solely to equalize length, and do not remove an option that represents a meaningful misconception. Any removal must update accepted-answer references, option-targeted feedback, and the applicable existing validation/scoring checks.

This correction does not change the separate i002 ambiguity finding, any per-item identity recommendation, or the overall REVISE verdict. It adds no option-count, equal-length, or warning-count gate. For comparison, the existing B06 unit uses four choices and its mechanical schema/scoring/reversal check passed; that confirms only that four choices can be valid under an existing unit contract, not that B01’s specific mode automatically permits a reduction. The B01 correction must be checked against its actual contract.

The original reports remain byte-for-byte historical records. The clarification is limited to interpreting the correction recommendation under §4.3.
