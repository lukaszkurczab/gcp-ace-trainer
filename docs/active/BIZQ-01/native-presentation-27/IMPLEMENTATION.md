# Overall scoring 27 implementation

## Change

The accepted PO decision is implemented as a separate overall-credit projection: a correct attempt contributes its existing earned points, while partial and incorrect attempts contribute zero. The stored attempt result, raw aggregate evidence, scorer checks, diagnostic kind/count, and all existing denominators remain unchanged.

`application/canonical/overallScoreCredit.ts` owns the rule. Certification Practice and Exam projections expose verified `overallPointsEarned` alongside the existing raw point total. The Coding completed-result facade exposes the same derived value alongside its raw validated score; abandoned results keep `null`. Result screens use the derived numerator, and omit an overall weighted row where the existing generic Design summary has no compatible verified-attempt projection. Certification Practice loads its exact points projection as optional: if that extra lookup fails, the existing count summary remains available and the weighted row is omitted. Existing mandatory coverage and raw-evidence checks remain in place.

The two existing Progress numerators now use the shared policy: installed-package performance areas and Coding effectiveness. Their point maxima, answered counts, diagnostic outcomes, and other progress rules are unchanged. The English locale already renders `Partial` as “Partly correct,” so no locale change was needed.
