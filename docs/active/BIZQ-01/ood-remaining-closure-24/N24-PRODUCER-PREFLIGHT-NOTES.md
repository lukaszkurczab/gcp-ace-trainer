## Concrete risks and falsifiers

- The private v23 reconstruction assumption fails if any of the 18 N08/N09 paths overlap a v23 proof source or if v23's validator reads their bytes outside `canonical`. The current fixed v23 descriptor lists N07 paths; the v24 proof must bind disjoint paths and a test should prove that fact.
- Historical fixture expansion is incomplete if any v23-or-older test starts from the live v24 catalog but bypasses the new v24-to-v23 restoration step. Search every fixture call site, not just the N23 test.
- Preserved-1089 evidence is insufficient if checked only by count. Bind the exact manifest-supplied preserved QSet and verify those objects byte/canonical-equal to the accepted v23 source, while separately reconstructing the full v23 QSet.
- The final map could contain same-ID edits as well as question replacements. Any implementation that assumes all 324 use replacement IDs, or merges both categories into one proof list, would weaken the already established proof meaning.
- Candidate admission does not itself read the semantic proof. It consumes the new exact candidate release and synchronized app locks; do not claim candidate/admission evidence before the content snapshot, app sync, and real existing gates run.

No code was changed and no tests/build/admission were run for this preflight. The notes describe repository hooks, not a producer design PASS or full BIZQ-01 acceptance.
