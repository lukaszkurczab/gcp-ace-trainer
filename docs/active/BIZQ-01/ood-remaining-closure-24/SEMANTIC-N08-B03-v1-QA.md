## Blocking findings

The key choices repeatedly name the complete atomic transition and repeat several decisive fields from the prompt, while the wrong choices commonly present a single partial update, a caller repair, or a global lock. Fourteen of 18 keys are strictly longest. This is not blocking because of the count: the content itself repeats the same form pattern. For example, i007’s accepted choice names a multi-step effective-sequence publication boundary at 138 characters against an 84-character longest distractor; i018’s key is 140 characters against 93. A learner can repeatedly select the most complete-sounding option without distinguishing the exact boundary. Revise the choice sets toward plausible, complete alternatives that require comparing the stated invariant; do not restore long keyed prose or pad distractors.

A second issue is that global-lock distractors are diagnosed as wrong because they block unrelated work, though several stems do not state that unrelated work must continue. In i003 the case describes remapping one episode but does not require other episodes to remain writable; i004 concerns one temporary grant and does not state unrelated permission checks must remain available. A global lock, if observed by relevant readers and writers, can still satisfy the stated coherence requirement. Inefficiency alone is not a correctness failure. For the affected cases, include an existing-objective fact about independent work/availability where that distinction matters, or replace the distractor with a plausible strategy that visibly violates the stated invariant. This is not a new throughput requirement; it follows the unit objective to separate the smallest coherent state change from unrelated workloads.
